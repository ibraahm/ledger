# 📖 Read Me First — Setup (10 minutes)

Vault name: **TENFOLD** — because the mission is 10x, and the brain should be named after the outcome.

Built for: **an Enneagram 3w2 / INTP on the CEO track** who thinks in strategy and stories, wins through people, and whose only real enemy is the perfectionism → procrastinate → panic loop.

## 1. Install
- Phone (your main device): get **Obsidian** from the App Store / Play Store
- Open it → **Open folder as vault** and point it at this unzipped `TENFOLD` folder
- Desktop later: download from obsidian.md, open the same folder
- To sync phone ↔ laptop: **Obsidian Sync** (paid, easiest) or iCloud Drive / Google Drive folder

## 2. Settings (2 minutes, do these)
- Settings → Core plugins → turn ON: **Daily notes**, **Templates**
- Daily notes → New file location: `60 Daily` → Template file: `90 Templates/Daily Note Template`
- Templates → Template folder location: `90 Templates`
- Mobile → set the **"+" quick action** to open today's daily note

## 3. Your three rules (from your own test results)
1. **Capture ugly.** Perfectionism killed your last systems. A one-line messy note that exists beats a beautiful note that doesn't. You polish for an audience — the Inbox has no audience.
2. **Log wins the day they happen.** Your equity case is built from receipts, and receipts fade in 48 hours.
3. **If you did it twice, write the playbook.** You said everything is on you. Every SOP you write is a future employee's job description — and evidence you built systems, not just outcomes.

## Why this structure fits you
- You remember **stories** → every template asks for the story, not just bullets
- You learn by **explaining** → book notes are written as if teaching someone
- You read **people** → the People folder is your CRM and negotiation prep
- You produce under **deadlines** → the Friday review is a manufactured deadline
