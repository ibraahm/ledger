# 🤖 AI Engine — turning TENFOLD from storage into a strategist

> A vault alone is memory. A vault + an LLM grounded in it = an AI chief-of-staff that knows YOUR business, YOUR owner, YOUR wins — and can reach out to the live web when it needs fresh intel.

## Option A — Claude Desktop connected to this folder (most powerful)
Claude Desktop can be given access to local folders (via connectors/MCP), so it can **read and write your vault directly**: query your Win Ledger, draft the equity pitch from your own receipts, update Owner Intel after you paste a conversation — and use **web search** for anything outside the vault (market comps, supplier pricing, negotiation benchmarks).
- Setup guide: https://support.claude.com (search "connect local files / MCP")
- Give it the folder: `TENFOLD`
- Paste [[TENFOLD System Prompt]] as your project/system instructions

## Option B — AI inside Obsidian (works on the go)
Community plugins that chat with your vault using an API key:
- **Copilot for Obsidian** — chat grounded in your notes (RAG), supports Claude/OpenAI models
- **Smart Connections** — surfaces related notes automatically, chat over vault
- Settings → Community plugins → Browse → install → add your API key
⚠️ Your vault will contain sensitive business intel — only use plugins/models you trust, and check what data leaves your device.

## Option C — Claude Project (zero setup, 5 minutes)
On claude.ai, create a Project called **TENFOLD**, upload the key files (Value Scoreboard, Owner Intel, Win Ledger, Equity Pitch), and paste [[TENFOLD System Prompt]] into the project instructions. Re-upload files as they grow. Claude's built-in web search covers the "crawl the web when needed" part.

## When the AI should hit the web (tell it so — it's in the prompt)
- Market size / competitor moves for the 10x plan
- Benchmark data: typical margins in your industry, standard equity/phantom-equity structures for operator-CEOs
- Due diligence on suppliers, clients, hires
- Anything time-sensitive — never from memory
